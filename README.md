# e-store

## Сборка приложения

## Версия приложения release_v2. Спринт 6
**Сборка осуществляется с помощью maven, версия java 21, используется база данных postgresql. Для запуска используется docker-compose. Для сборки необходимо:**
1. Перейти в директорию с pom.xml. Выполнить команду "mvm clean install".
2. В директории target будет создан simple-electronic-store.jar, запуск jar файла осуществляется в докер-контейнере.
3. Для создания image и его запуска необходимо в директории ./extra выполнить команды:
   1. docker-compose build
   2. docker-compose up
4. Будет создан контейнер с образом приложения и образом бд postgresql.
5. Приложение будет доступно по адресу: http://localhost:8080/
6. Для удобства запуска в директории extra находится run.sh скрипт с командами необходимыми для запуска приложения.


## Версия приложения release_v1. Спринт 5
**Сборка осуществляется с помощью maven, версия java 21, используется база данных h2. Для запуска использовать dockerfile. Для сборки необходимо:**
1. Перейти в директорию с pom.xml. Выполнить команду "mvm clean install".
2. В директории target будет создан simple-electronic-store.jar, запуск jar файла осуществляется в dockerfile.
3. Для создания image и его запуска необходимо в директории с Dockerfile выполнить команды:
    1. docker build -t e-store .
    2. docker run -detach -p 8080:8080 e-store
4. Приложение будет доступно по адресу: http://localhost:8080/
5. Для удобства запуска в директории extra находится run.sh скрипт с командами необходимыми для запуска приложения.

## Описание приложения
Данное приложение представляет собой витрину товаров. 
Для удобства демонстрации функционала в левом верхнем углу предусмотрена загрузка товаров из csv файла.
В директории extra можно найти файл productForUpload.csv, с примерами товаров. 

На главной странице с продуктами можно увидеть карточки продутов с названием товара, ценой, изображением и возможностью добавить/удалить товар из корзины.
Товары можно фильтровать по названию и описанию, сортировать по цене и алфавиту. Также, добавлена пагинация.

Помимо этого, можно перейти в карточку конкретного товара. На ней также представлено описание товара и возможность удаления товара из корзины.

В правом верхнем углу представлены две кнопки: с корзиной и заказами. В корзине можно увидеть общую сумму заказа и формить заказ.

Все завершенные заказы отражаются на странице заказов.
